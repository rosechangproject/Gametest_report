Rose 的 QA 自動化測試練習

這裡記錄了我從 API 分析、數據統計到自動化部署的學習歷程。每個專案都整合了 Python 腳本分析與前端視覺化呈現。

題目一：API 資料統計與分析報告

Python / JSON / Data Analysis

練習目的： 運用 Python 腳本自動化處理原始 API 資料，將複雜的欄位資訊轉化為易於閱讀的格式，並透過雲端同步提升資料管理效率。

技術重點： 使用 Antigravity 框架撰寫自動化腳本，實作英文欄位自動翻譯為繁體中文並進行資料格式化。整合 AI 運算邏輯，針對「追殺局」玩家贏錢比例進行精確計算並設定警示機制。

題目二：遊戲數值回測監控 Dashboard

Python / HTML / GitHub Pages

練習目的： 將測試產出的原始資料轉化為結構化的視覺報表，提供團隊清晰、具備高度回溯價值的品質監控成果。

技術重點： 串接前段處理完成的資料並套用 Allure 報表框架，實作完整的欄位映射與 Log 紀錄整合。

題目三：Jira Bug 數據自動化統計工具

Python / Flask / Jira API / Pandas

練習目的： 解決手動統計 Bug 的耗時問題，透過 API 自動化抓取數據並產出視覺化報表與 Excel。

技術重點： 串接 Jira REST API、環境變數資安管理、支援雲端演示模式與內網真實模式雙切換。

題目四：LINE 代辦事項及日曆小精靈

FastAPI / LINE Bot / Google API

練習目的： 打造多用戶數據隔離的自動化管理排程系統。使用者在 LINE 端輸入指令，系統將透過異步微服務架構，精準完成試算表分頁數據隔離保護，以及 Google 日曆雙向智慧同步功能。

技術重點： 巨型代碼完全重構，全面落實「職責分離」；採用新版 FastAPI 官方首選的 lifespan 機制，優雅管理背景定時巡邏廣播鬧鐘的安全生命週期。

🚀 進入展示頁面

題目五：AI 天氣推播 Agent

Python / GitHub Actions / Dify / LINE API

練習目的： 打造每日自動化天氣提醒服務，將中央氣象署天氣資料與環境部 AQI 資料整理成結構化 JSON，再交由 Dify 產生自然語氣文案，最後透過 LINE Messaging API 主動推播。

技術重點： 串接多個外部 API、使用 GitHub Actions 排程自動執行、透過 GitHub Secrets 管理金鑰，並加入早晚模式、錯誤處理、語法檢查與 log rotation，讓小型自動化服務具備可維護性。

🚀 查看 GitHub 專案

題目四：LINE 多用戶代辦事項及日曆小精靈 (實機功能模擬)

FastAPI / LINE Bot SDK / Google API / APScheduler

練習目的： 打造多用戶數據隔離的自動化管理排程系統。使用者在 LINE 端輸入指令，系統將透過異步微服務架構，精準完成試算表分頁數據隔離保護，以及 Google 日曆雙向智慧同步功能。

架構亮點： 巨型代碼完全重構，全面落實「職責分離」心法；採用新版 FastAPI 官方首選的 lifespan 機制，優雅管理背景定時巡邏廣播鬧鐘的安全生命週期。

⚠️ 核心代碼（Python）目前安全運行於個人 Private Repository 與雲端 Render 生產環境。為保護個人私密 API 金鑰安全性，下方沙盒全面 1:1 模擬後端核心雙向同步運作邏輯，歡迎點擊 LINE 快捷面板體驗。
